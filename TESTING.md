
# Student Study Planner — Testing Checklist

## Input Validation
- [ ] Student can provide subjects and study tasks.
- [ ] Class timetable and available study hours are accepted.
- [ ] Exam dates and assignment deadlines are handled.
- [ ] Missing or invalid information is explained clearly.

## Study Schedule
- [ ] A daily study plan is generated.
- [ ] Study sessions fit within available time.
- [ ] Class times and study sessions do not overlap.
- [ ] Breaks are included.
- [ ] Urgent deadlines receive appropriate priority.
- [ ] The plan can be adjusted when tasks change.

## AI Agent and Tools
- [ ] Agent starts successfully.
- [ ] The scheduling logic returns a usable timetable.
- [ ] Invalid requests are handled safely.
- [ ] Tool/API failures are handled gracefully.

## Fetch.ai Integration
- [ ] Agent is registered on Agentverse.
- [ ] Required ACP interaction is tested.
- [ ] Agent can be discovered and used through ASI:One.
- [ ] Complete study-planning workflow works through ASI:One.

## Final Submission
- [ ] README has accurate setup instructions.
- [ ] Agent names and addresses are documented.
- [ ] Public repository link works.
- [ ] ASI:One shared conversation link works.
- [ ] Demo video is 3–5 minutes long.
- [ ] Required submission steps are completed.
