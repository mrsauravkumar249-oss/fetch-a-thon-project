
# Student Study Planner — Test Plan

## 1. Generate a Realistic Timetable
- [ ] Accept subjects, exam dates, difficulty, and available study hours.
- [ ] Prioritize subjects based on urgency and difficulty.
- [ ] Include breaks and revision sessions.
- [ ] Never schedule two tasks at the same time.
- [ ] Keep study sessions within available hours.

## 2. Recover Missed Study Sessions
- [ ] Allow the student to report a missed session.
- [ ] Recalculate the remaining available time.
- [ ] Prioritize unfinished tasks and upcoming exams.
- [ ] Preserve breaks and revision time.
- [ ] Explain when all tasks cannot fit in the remaining time.

## 3. Explain Planning Decisions
- [ ] Explain why urgent subjects are prioritized.
- [ ] Explain how difficulty affects scheduling.
- [ ] Explain why breaks and revision are included.
- [ ] Give honest explanations based on the actual schedule.

## 4. Planning Tool
- [ ] Validate the student's input.
- [ ] Return a structured timetable.
- [ ] Handle missing or invalid inputs.
- [ ] Return understandable errors when planning fails.

## 5. Fetch.ai Integration
- [ ] Register the agent on Agentverse.
- [ ] Expose the planning tool through ACP as required.
- [ ] Test the agent interaction.
- [ ] Complete the workflow through ASI:One.

## 6. Final Demo and Submission
- [ ] Demonstrate timetable generation.
- [ ] Demonstrate a missed-session recovery.
- [ ] Demonstrate the explanation of a planning decision.
- [ ] Verify the public GitHub repository.
