
# Team Contribution Guide

## Before contributing
- Confirm your task with the team.
- Read the project README.
- Never commit API keys, passwords, tokens, or private agent seeds.

## Team roles
- Member 1: Main AI agent
- Member 2: Tools and APIs
- Member 3: Fetch.ai integration
- Member 4: Testing, documentation, and demo

## Code sharing
- Tell the team which files you are changing.
- Test your changes before sharing.
- Explain how to run your code.
- Coordinate before changing shared files.

## Testing
- Follow TESTING.md.
- Record actual test results.
- Report errors and blockers to the team.
